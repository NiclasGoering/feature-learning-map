- Read the main text and Methods of the HTML version; the Supplementary Materials (hyperparameters, CIFAR-10 ResNet, Figs. 7-9) were not read, so the CIFAR-10 and other-task width trends are taken from the main text.
- `learning_rule: [bayes, gd]` is a judgement call: the max-entropy state is the equilibrium of a flat measure on a bounded parameter box, conditioned on train loss, and it is compared with SGD (Adam for the width study). No likelihood or temperature is defined, so the dial `temperature` is `not-stated`.
- No scaling limit is analysed: the networks are finite and the evidence is numerical. The validator requires a regime tag for any paper with `bayes`, so R6 (classical thermodynamic, entropy of the weight space at fixed data) and `high-dim` were chosen as the closest fit; this is a forced classification and should be checked.
- Parameters are confined to $[-2/\sqrt{W},2/\sqrt{W}]$, so the entropy depends on that range; the paper says the range does not change results qualitatively but shows no data in the main text. Absolute entropy is defined only up to a constant.
- The polymer task fine-tunes only a regressor head on frozen transformer embeddings, so it is not a full transformer. Test accuracy for WLMD is a smoothed sigmoid surrogate (Eq. 2).
