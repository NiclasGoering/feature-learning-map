one_line: "A rigorous formula for convex last-layer learning with jointly Gaussian teacher and student features captures real-data learning curves for fixed or pre-trained feature maps."
summary: "The paper defines a Gaussian covariate teacher-student model in which teacher and student see different feature maps with a general joint covariance. For convex losses with $\\ell_2$ regularisation it proves, with Gordon's comparison inequalities, closed-form training and test errors in the limit $n,p,d\\to\\infty$ at fixed ratios; the same result follows from replicas. It conjectures that the model also describes real data, and tests this on random features, kernels, GAN-generated images with learned features and Fashion-MNIST, where ridge regression agrees well. The framework fails for some logistic cases on real images."

- Read the HTML of v3 up to Sec. 3.4 and the table of contents of the appendices; the proof (App. B, Gordon comparison) and the replica derivation (App. A) were not read.
- `learning_rule: [gd]` is a placement choice: the estimator is the minimiser of a convex last-layer empirical risk, not a Bayes posterior and not an explicit gradient descent. `bayes-optimal` thread is from the paper's relation to the vanilla teacher-student model; no Bayes-optimal result is stated.
- Thm 1 is the $\ell_2$-regularised special case of Thm 2 (generic convex loss and regulariser, non-asymptotic). The mechanism fields refer to the last layer on fixed features, so labels are T0 for the theorems and `not-analysed` where learned features appear.
- The fixed-point equations need the joint spectral measure of $\Omega$ and the teacher projection, which for real data come from the empirical covariances (grade `B`).
- Examples where the model does not match (real CIFAR10 images, logistic regression) are in the Fig. 3 caption; Sec. 3.1 (random kitchen sink) and Sec. 3.2 (kernel methods, Fig. 2) are not recorded as separate results.
