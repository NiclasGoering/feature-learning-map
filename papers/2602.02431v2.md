summary: "The paper studies a Gaussian single-index model with an even link, the quadratic or its truncation, where one-pass SGD needs $n\\gtrsim d\\log d$ samples. For the unbounded quadratic, full-batch spherical gradient flow on the correlation loss fails below $d\\log d$ samples. With a smooth truncation, the same flow reaches weak recovery with $n\\gtrsim d$, using a uniform BBP transition for the matrix that drives the flow. Euclidean GD on the squared loss from small initialisation then reaches strong recovery in $O(\\log d)$ steps, with geometric convergence after a search phase."

- Read Sections 1 to 5 of the HTML version in full; the appendices (proofs, Props B.1-B.5, D.1-D.26) were not read.
- Venue taken from the arXiv comment "Accepted to ICML 2026".
- Mechanism label: the paper's mechanism is a BBP-type outlier of the data matrix $A(\theta)$ whose top eigenvector aligns with $\theta^\star$ and which the weight vector follows. Another open ingest pull request adds `hessian-outlier-alignment` for a close case, but copying that file into this branch makes `validate.py` fail (`introduced_by` must be a paper in this branch), so I used the existing `rank-one-spike` as the nearest label. A checker may want to switch to `hessian-outlier-alignment` after that pull request merges.
- The model is a single neuron with quadratic activation, hence `depth: one-hidden-layer` and `architecture: other`. Both Thm 3.2 and Thm 4.1 use a truncated quadratic, and Thm 3.1 the plain quadratic; the claim of a gap over one-pass SGD relies on the Ben Arous et al. lower bound for information exponent 2, quoted not proved here.
- Conditions: $M$ is a large constant; Thm 4.1 uses a hard truncation while Thm 3.2 uses a smooth one, "for technical convenience".
