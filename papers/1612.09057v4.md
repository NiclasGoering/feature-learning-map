one_line: "On tree-structured Markov generative models, a recursive ancestral-reconstruction algorithm labels all unlabelled data, while local and shallow (low-order-moment) algorithms provably cannot."
summary: "The paper defines three hierarchical generative models on a $d$-ary tree: independent symmetric mutation, per-edge changes of representation, and pairwise feature interaction. Labels are attached to subtrees, and the task is semi-supervised labelling of the leaves. A recursive algorithm that reconstructs the tree and then the ancestral representations labels all well-represented classes when $d\\lambda^2>1$ (or $d\\lambda>1+\\varepsilon$) and $q$ is large. Information-theoretic lower bounds show that local algorithms, and shallow algorithms using only low-order label-conditional moments, do no better than chance. The proof strengthens the fact that belief propagation is not approximated well by linear functions."
