summary: "Inputs are sparse combinations of orthonormal patterns, and labels depend on how many of $k$ class-relevant patterns are present among $D$, with background patterns added at rate $p_{\\rm o}$. A two-layer network with hinge loss, unbiased initialisation and Gaussian neuron noise is trained by GD. The first step makes neuron weights roughly proportional to the sum of the class-relevant patterns, the second improves their signal-to-noise ratio, and later steps fit a classifier on these features. Linear models on data-independent features need exponentially many features, and replacing the input structure by a uniform law makes all polynomial SQ algorithms fail."

- Read the HTML version through Sec. 5.2 (theorem statements and proof sketches). The appendix proofs were not checked. Sec. 6 runs synthetic simulations and real-data experiments on MNIST, CIFAR10 and SVHN (SVHN is listed as `other-real`).
- Model: truncated ReLU $\sigma(z)=\min(1,\max(z,0))$ with injected Gaussian noise on the neurons, hinge loss, $\ell_2$ regularisation, unbiased symmetric initialisation (the network output is zero at start). Training is full-batch GD on the population loss with different step sizes at each step; the first two steps matter, the rest is convex learning on the learned features.
- Mechanism: the first-step weights proportional to the sum of the relevant patterns resemble the label `support-sum-neurons` from another open pull request, but `validate.py` requires the introducing paper to be in the same branch, so I used `not-analysed`. This is a candidate to relabel after that pull request is merged.
- r2 compares to fixed-feature models, not to a Bayesian rule, so `compared_other_rule` is "no".
- The label function is any binary function of the number of present class-relevant patterns (here parity-like cases make the lower bounds), so `target` is `other`.
