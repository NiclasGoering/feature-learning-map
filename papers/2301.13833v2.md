summary: "The paper studies learning $k$-parities on Boolean inputs with a two-layer network trained by SGD, where the input distribution changes during training. A first step on a product distribution with bias $p$ close to $1$ makes support coordinates distinguishable and recovers the support; a second stage on the uniform distribution fits the readout. This yields polynomial cost in $d$ for hinge and covariance losses, against the $d^{\\Omega(k)}$ bound without curriculum. For Hamming mixtures, the paper proves that any curriculum with a bounded number of steps fails under noisy GD with bounded gradient precision."

- Read the full HTML (v2) including the proof set-up of App. A.1-A.2 (Lemmas 1-3); Appendices B-D read only in outline. Venue from arXiv journal-ref.
- Training is layer-wise in the proofs: one first-layer step on the biased batch, then the readout on uniform data. `learned_layers: [all]` records that both layers are learned, but by separate stages. Initialisation and learning-rate schedules are chosen for the analysis (the paper says so in Sec. 3.1), so `parametrisation` is set to `sp` as the closest slug, not a stated scaling.
- Mechanism: the biased-measure gradient gap in r1 and r2 (Lemma 1) resembles the label `fourier-gap-amplification`, which is added only in open pull request branch ingest/2026-10-23-9. The validator needs a label's introducing paper in the same branch, so `not-analysed` is used here; switch after that PR merges.
- Thm 3 uses the ramp activation, Thm 4 uses ReLU; experiments use ReLU MLPs with square loss (Sec. 3.2).
- The curriculum needs an oracle for samples from several product measures (stated limitation in the Introduction). The continuous curriculum for Hamming mixtures is only conjectured to help (Sec. 2, Def. 4); no result is recorded for it.
- `exponents-leaps` thread chosen because the cost drops from $d^{\Omega(k)}$ to $d^{O(1)}$; the paper does not use the leap-exponent language.
