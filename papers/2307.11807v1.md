summary: "The paper builds on the Bayesian effective action of one-hidden-layer networks at $P/N_1\\to\\alpha_1$. For a fully connected layer it notes that the single order parameter only rescales the readout prior, so finite width cannot beat a tuned infinite-width kernel. It then derives an effective action for one convolutional hidden layer, in which the kernel carries a matrix of order parameters $\\bar Q_{ij}$ coupling pairs of patches, so the network can select data-dependent local components. Locally connected networks without weight sharing only renormalise the diagonal. Zero-temperature predictions for the change of the internal similarity matrix and for the bias are checked with training on synthetic data and CIFAR-10."

- Read the full HTML of v1 (main text; Appendices A–D were not read in detail). The arXiv metadata gives no journal reference, so `venue` is `preprint`.
- The CNN action rests on the same Gaussian-equivalence assumption as the fully connected case (Breuer-Major argument), which requires $N_0$ to grow with $P$ and the stride to scale with $N_0$. Results are therefore `phys`.
- The paper says the renormalised kernel cannot be measured directly. The similarity-matrix test (r4) uses GD with Adam, not a Bayesian sampler, and the paper stresses the theory is valid only in the Bayesian setting; the bias test (r5) uses zero-temperature Langevin.
- The matrix $\bar Q_{ij}$ over patch pairs is a richer object than the scalar-per-patch of the label name, which is why it can change the mean predictor; the label `patch-scale-renormalised` was reused for it.
