summary: "The paper studies binary classification of a four-component XOR-like Gaussian mixture in dimension $D$, with $N\\propto D$ samples. For a two-layer network with $K=O(1)$ hidden neurons trained by one-pass SGD, it derives closed ordinary differential equations for the overlaps of the weights with the cluster means, and a reduced fixed-point system for the long-time error. For random features with $P\\propto D$ it gives the asymptotic error via Gaussian equivalence. Small networks come close to the oracle error at all signal-to-noise ratios, while random features and kernels only beat chance at diverging signal-to-noise ratio. Over-parametrisation speeds convergence but does not change the final error."

- Read the HTML version through Secs. 1 to 4 (main text); the appendices with the ODE derivations and the Gaussian-equivalence calculation were not read.
- The authors say the derivations are not rigorous but could be made so with the methods of Wang et al. 2019 and Goldt et al. 2019, so r1 to r3 are `phys`. Training uses squared loss on one-pass (online) SGD; the ODE is for equal covariances in each Gaussian.
- `learning_rule: [gd]`: the "comparison" in r3 is with random features and kernels, not with a Bayes rule, so `compared_other_rule` is "no". The Bayes oracle only appears as a reference error (Eq. 3).
- Random features (r3) use $P\propto D$ and online SGD on a linear readout; the paper says kernel performance is recovered for $\gamma\to\infty$. Their Gram-matrix grade is B because the formula needs the feature covariance spectrum.
- Fig. 1 states the random feature error at $D=10000$, $P=2D$ and the 2LNN error at $D=1000$.
