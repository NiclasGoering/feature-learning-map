summary: "The paper studies matrix sensing, where a high-rank signal matrix with a rotationally invariant prior is observed through $n\\propto d^2$ noisy linear or generalized linear measurements. Three ingredients give a rigorous formula for the Bayes-optimal free entropy and minimum mean-square error: a universality result replacing structured sensing matrices by Gaussian ones, an adaptive-interpolation argument for generalized linear models with such priors, and known results on matrix denoising. Applications include a two-layer network with quadratic activation and extensive width, and bilinear sequence regression, for which earlier replica predictions are proved. No numerical experiments are reported."

- Read the main text (Secs. 1-3) of the HTML version; the appendices (universality proof, interpolation, denoising inputs, rectangular case) were only skimmed. Anchors checked against the arXiv HTML.
- Statements Thms 2.4 and 2.5 are for the symmetric model ($n/d^2\to\alpha$); Thms 2.8 and 2.9 are the rectangular counterparts, proofs only sketched (App. H). Thm 2.10 excludes $\kappa=1$ and needs a post-activation noise $\Delta_0>0$ the authors believe removable. The priors need $\mathcal V''\ge1/c$, a technical condition (App. A).
- The paper has no feature-learning analysis, so every result uses `not-analysed`. For r3 the proved reduction to estimating the second-order matrix $S^\star$ resembles the label `quadratic-term-alignment` defined in open pull request ingest/2026-10-23-3. It was not used because the validator requires the file's `introduced_by` paper (2408.03733v1) to be in the same branch. A checker may switch r3 to that label once both are merged.
- The width $m=\kappa d$ is extensive, so the network is high-dimensional in the sense of regime R6. Depth is one hidden layer for the network application; the general matrix-sensing results have no depth, so overrides set `architecture: [other]`.
- The paper states that the Bayes error for quadratic networks is a matrix-sensing error with effective noise $\tilde\Delta=2\Delta(2+\Delta)/\kappa+\Delta_0$.
