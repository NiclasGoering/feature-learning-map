summary: "The paper studies the prior output law of Gaussian fully connected networks whose hidden widths diverge at fixed ratios. For bounded continuous activations it proves a large deviation principle at speed equal to the reference width, with a rate function built from a layer-by-layer chain of kernel costs. Moderate deviations at intermediate speeds have a quadratic rate given by the NNGP covariance recursion. For a single input the result extends to deep ReLU networks, and shallow networks and their input derivatives are treated under general activations. No training or data labels are involved."

- Read v3 HTML in full for Secs. 1–2 and the statements in Secs. 4–5; proofs in Sec. 3 were not checked in detail.
- This is a statement about the prior (network at initialisation); there is no likelihood, so the Bayes tag and dial values describe the prior law, with R0 because the moderate-deviation rate equals the NNGP one. `p_vs_n: fixed` is a placeholder for a finite input set.
- Venue taken from the arXiv journal reference (J. Appl. Probab. 63 (2026) 96-115).
- Mechanism `kernel-fixed-at-init` is used loosely: the large deviations of the random kernel are the object of study, but the paper does not interpret them as feature learning. The LDP speed is the width of the reference layer.
- The explicit ReLU rate is for $|A|=1$ only; the multi-input ReLU case is not covered.
