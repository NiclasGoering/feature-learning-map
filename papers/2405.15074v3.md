summary: "The paper studies one-pass SGD on a power-law random-features regression model with three parameters: data complexity $\\alpha$, target complexity $\\beta$ and parameter count $d$. A deterministic equivalent turns the expected loss into a Volterra equation, which is bounded above and below by a forcing function (gradient descent) and an SGD-noise kernel. Four terms dominate in different regions of the $(\\alpha,\\beta)$ plane, giving four phases and three subphases with explicit compute-optimal loss and parameter-count exponents. In three phases the optimal parameter count scales as $\\mathfrak{f}^{1/2}$ with the compute $\\mathfrak{f}$. Simulations agree with the formulas, though finite-$d$ exponents drift slowly."

- Read the main text (abstract to conclusion) and the statement of Thm 2.1; the appendix proofs (Secs. B-J) were not read.
- Status `thm`: the paper proves its statements for the deterministic equivalent of the resolvent, not for the actual random matrix (its footnote 8 says the comparison is left open and supported numerically). Thm 2.1 needs $\alpha>1/4$ and $\beta<1+2\alpha$; the authors expect it for all $2\alpha+2\beta>1$.
- Fit to the schema is loose: this is a scaling-law paper for a linear random-features model. `width_limit: high-dim` and `learned_layers: readout-only` are judgement calls. `gd_time: other` because the training time $r\sim\mathfrak{f}/d$ is set by the compute budget.
- r3 and r4 list `not-analysed` because there is no feature-learning mechanism to name. Exponents for all phases are in a table in Sec. 3; the table has no anchor in the HTML.
- No venue is printed in the HTML or the arXiv record, so `venue: preprint`.
