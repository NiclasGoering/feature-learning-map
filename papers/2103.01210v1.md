summary: "The paper asks whether gradient descent on a differentiable model can succeed only by amplifying a weak advantage of its tangent kernel. For any smooth loss and an unbiased initialisation, it proves that GD reaching small error forces the tangent kernel at initialisation to have an edge over null prediction that is inverse polynomial in the model scale. For the square loss and any initialisation, an average of tangent kernels at a random initialisation depending on the input law has such an edge. Constructions on biased sparse parities and leaky parities show that both the unbiasedness and the input-distribution dependence are needed."

- Read the HTML version through Sec. 5 and the survey in Sec. 6 (table of prior separations); appendix proofs were not checked.
- Setting is general: any differentiable model of size $p$ with bounded gradient scale $C_f$. The explicit constructions are a sigmoidal network with piecewise-quadratic activations of depth $O(\log n)$, which the paper calls unnatural, so depth lists both values.
- Edge means the improvement of the loss over null prediction ($\mathcal L(0)=0.5$ for square loss with binary labels). Thm 1 holds for any smooth loss; the lower bounds are for square loss.
- r3: the mechanism (larger first-step gradient on support coordinates, from biased bits) resembles `fourier-gap-amplification`, a label that exists only in another open pull request; `validate.py` requires the introducing paper to be in the same branch, so I used `not-analysed` and left the match to a later merge.
