summary: "The paper considers a student network sampled from a distribution absolutely continuous with respect to the uniform one on the set of parameters that fit the training data exactly. Using dimension theory of real analytic sets, it shows that with probability one the sampled student equals the teacher function once the sample size exceeds the parameter dimension minus the dimension of the set of teacher-equivalent parameters, plus one. For deep linear students the threshold is the number of teacher parameters plus one, whatever the student size; for analytic fully connected networks it is given by a sum over layers. Experiments with near interpolators on deep linear networks and on LeNet with MNIST agree with the bounds."

- Read the main text (Secs. 1-7) and the statements of all theorems; proofs (App. B-E) and the appendix experiments (F.4, pattern search) were not checked.
- Regime tag: the validator requires one for `bayes`. The paper has no scaling limit; all results are non-asymptotic. R6 with `high-dim` is a forced fit and should be reviewed; `finite-exact` is the honest width group.
- Posterior reading: a random interpolator is a draw from a law absolutely continuous with respect to the uniform law on the zero-training-error set, i.e. a zero-noise posterior with a uniform prior on a compact parameter set. The paper does not use the word Bayes. r5 mixes this with Adam-sampled near interpolators for LeNet, which the paper itself calls an approximation of unbiased sampling. The r5 override to `[bayes, gd]` records this, with rough GD defaults (`constant`, `to-convergence`).
- Thm 6 as printed has $m_{\ell-1}$ for the student width and $m^*_\ell$ for the teacher width, so the threshold depends on the student's widths. The text after Thm 5 says over-parameterisation does not raise the threshold for deep linear networks, while Sec. 1.1 says there are cases where it lowers it; the exact comparison for FCDNNs is not worked out in the main text.
- The mechanism label was added because the paper explains it in Sec. 4.3 (proof outline). The fit to T4 is loose: the collapse is onto an analytic set of positive dimension, not onto atoms.
