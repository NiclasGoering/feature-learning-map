- Read Secs. 1-5 of the HTML v4 in full; the appendices (replica derivation, saddle-point equations, numerics) were read only where they state settings.
- Notation: the paper writes $N$ for input dimension and $K$ for width; the entry uses $D$ and width, as in the vocabulary. The readout weights are fixed (not learned), so `learned_layers: first-layer-only`. The theory treats $D\to\infty$ first and then $K$ large, a sequential limit that the authors say is consistent with a joint scaling $K=o(D)$.
- Grade A: the order parameters solve scalar replica equations that depend only on the teacher and $\tilde\alpha$; the expectations need numerical quadrature. The Gaussian closure is the CLT over $K$ hidden units. Mixing is `critical` because the theory predicts coexisting branches exactly where Langevin samples are compared, and the authors report a hard phase for random initialisation.
- r4: GD is Eq. (141) at $T=0$, random i.i.d. $\mathcal N(0,1)$ init, learning rate chosen per $\tilde\alpha$ in $[10^{-4},10^{-1}]$ (smaller for larger $\tilde\alpha$), so `gd_step_size: constant` holds per run only. App. F writes the loss with $\lambda\Vert W\Vert^2$ and $\ell=(y-\hat y)^2$, the main text (Eq. 2, Fig. 5) with $\frac\lambda2$ and $\frac12(y-x)^2$; same ratio.
- r3 compares ERM at fixed and tuned $\lambda$ with the Bayes-optimal error (Fig. 5 right), but the comparison is theory against theory (no GD), so `compared_other_rule` stays `no` (the validator ties `yes` to Bayes against GD).
- Classification numerics: App. F says $K=100$, the Fig. 4 caption $K=10$; the paper is inconsistent.
- The paper reports GD matching ERM only qualitatively in places; it says finite-size effects and planted initialisation can push the error below the Bayes-optimal bound. Year is that of the first version (2025); the arXiv record carries no venue.
