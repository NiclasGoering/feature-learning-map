one_line: "On the Random Hierarchy Model, deep networks need $P^*\\simeq n_c m^L$ samples, the point where label correlations with low-level features appear and synonym-invariant representations form."
summary: "The Random Hierarchy Model generates labelled data from a tree of random composition rules, where each class or feature has $m$ equivalent (synonymic) lower-level representations. Deep CNNs and MLPs in the maximal-update scaling reach low test error at $P^*\\simeq n_c m^L$, polynomial in the input size, while two-layer networks and lazy deep networks need a fraction of all data. Hidden representations become invariant to exchanging synonyms at the same sample size. A signal-versus-noise argument shows that this is when correlations between input patches and the class become detectable, and a one-step gradient analysis of a two-layer network builds the invariant representation. Removing the correlations restores the curse of dimensionality."

- Read the main text in full. Appendices A to F (details of training, the full signal-to-noise calculation, the clustering result) were only skimmed. Section numbers in the paper are Roman numerals; the arXiv HTML uses `S1`, `S2`, ... for them.
- All sample-complexity claims in r1 and r2 are empirical; the paper derives only the characteristic size $P_c$ (r3) and the one-step statement (r4), both by physics-level arguments with an independence assumption.
- The two-layer one-step result r4 uses the mean-field limit, one-hot patch inputs and a fixed Gaussian readout. The entry's paper default is the deep μP experiments.
- Optimiser details (learning rate and schedule) are in App. A; I did not record them, so the step size is `other`.
- In r5 I merged two observations from separate figures: two-layer networks (Fig. 2) and lazy deep CNNs (Fig. 14). The width override `inf-kernel` applies to the lazy deep networks only.
- Open problem op-06 cites this paper for the sample complexity $P^\star\sim n_cm^L$ and asks for a Bayesian analogue.
