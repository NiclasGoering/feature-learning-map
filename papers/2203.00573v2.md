one_line: "Replica learning curves of deep linear Bayesian regression: narrow layers cause double descent for random features but not trained layers; first-order width corrections agree."
summary: "The paper computes zero-temperature replica-symmetric learning curves for Bayesian linear regression, deep linear random-feature (RF) models and deep linear networks (NN) on isotropic Gaussian data, in the proportional limit $p,d,n_\\ell\\to\\infty$. Both deep models show sample-wise double descent with label noise; RF models also diverge when a hidden layer is narrower than the input, NNs do not. At fixed depth the best RF width depends on prior-target scale mismatch, while an NN is best as wide or as narrow as possible. At large width RF and NN curves share the first-order correction $\\ell\\alpha/\\gamma$ and differ at second order."

- Read the full HTML v2 main text (Secs. I-VI); the replica appendices A-D and E-F were not checked line by line.
- Zero-temperature (small likelihood variance) replica-symmetric theory; the RS ansatz is checked against exact fixed-disorder posterior averages (Appendix C-D) and numerics at $d=100$, not against posterior sampling, so `sampler: none`.
- Notation: $\alpha=p/d$, $\gamma_l=n_l/d$, $\sigma^2$ prior variance, $\eta^2$ noise, $\tilde\sigma^2=\sigma^2/(1+\eta^2/(1-\alpha))$.
- Tags: R1 (proportional, standard scaling) for r1, r2, r5; R2 for the $1/\gamma$ expansions; R6 because $d\to\infty$ with $p=\alpha d$. Result r3 and r4 override the width group to large-width.
- Mechanism labels are judgement calls: the paper compares random and learned features but names no kernel-level mechanism. r3 is T1, not T2: the $O(\alpha/\gamma)$ term is identical for random features (Eqs. 21, 32), so it is not a target-driven tilt.
- `moves_mean` is "no" for r2-r4: at $\beta\to\infty$ the NN posterior mean is the min-norm linear-regression interpolant (App. D, Eqs. D11, D13, D21); width and depth enter only through the null-space variance $z$.
- Equal widths, $u=[z/((1-\alpha)\sigma^2)]^{1/\ell}$ solves $u=1-\alpha/\gamma+(\alpha/\gamma)\tilde\sigma^{-2}u^{-\ell}$ (App. D, Eqs. D32-D37), the Li-Sompolinsky equation; Eqs. (33), (35) are its second-order expansion. Root selection: Eq. (30) / (B144).
